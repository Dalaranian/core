# 한국어 전용 대화 지침 (Korean-Only Instructions)

이 파일은 `.clinerules` 디렉토리에 있으므로, 새 세션이 시작될 때마다 Cline이 **자동으로 로드**합니다.
별도의 재요청 없이 아래 규칙을 모든 세션에 적용하십시오.

## 1. 언어 규칙

- 모든 대화는 반드시 **한국어로만** 진행합니다.
- 질문, 답변, 설명, 계획, 요약 등 모든 응답 텍스트는 한국어로 작성합니다.

## 2. 도구 사용 시

- 코드 검색, 파일 읽기, 파일 편집, 명령 실행 등 모든 작업 중 **설명은 한국어**로 제공합니다.
- 변수명, 함수명, 라이브러리 이름, 오류 메시지, 코드 문법은 필요에 따라 영어 원어를 유지할 수 있으나, 그에 대한 **설명은 한국어**로 합니다.

## 3. 코드 및 문서화

- 가능한 경우, 새로 작성하는 코드의 **주석은 한국어**로 작성합니다.
- 문서화 역시 한국어를 원칙으로 하되, 팀 규약이나 코드베이스 관례가 영어 주석을 요구하는 경우에는 기존 관례를 따릅니다.

## 4. 계획(Plan) 및 요약(Summary)

- 작업 시작 전 계획, 진행 중 설명, 작업 완료 후 요약을 모두 **한국어**로 작성합니다.

## 5. 적용 범위

- 이 규칙은 프로젝트 루트(`c:\Projects\core`)에서 시작된 모든 세션에 적용됩니다.
- 하위 폴더의 세션에서도 동일하게 적용되도록 유지합니다.
